# Chronicle browser extension (MV3)

Posts `page.focus` events to the daemon HTTP ingress at `http://127.0.0.1:9713/v1/events`.

## Load unpacked

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select this directory

Configure allowed domains in extension options (default: github.com, stackoverflow.com, docs.rs).
